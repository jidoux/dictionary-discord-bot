To get this to work, you'd need to set the DISCORD_API_TOKEN environment variable to your own discord bot token. Create an app in the discord developer portal to create a bot. In terms of specific permissions, you may need to do things in the discord developer portal to get things to work nicely. Under the installation tab, I went to guild install, added a scope of "bot", and added all the permissions. This tab also contains the "Install Link" which is how you add a bot to a server. I also went to the "Bot" tab, reset the token to copy it (this is the token which is the environment variable), and then checked "Presence Intent", "Server Members Intent", and "Message Content Intent". Whether those are needed, I don't know. I just followed a tutorial years ago for another bot I made, and am copying over the settings for this one.

You would need to install Docker to run this locally. Or, just run it without Docker. See the given Dockerfile for the Python dependencies of this bot. Note that the docker-compose.yml file leverages environment varialbes specified in a .env file. This is easy to setup - just put the same name of the environment varaible thats in the docker-compose file in the .env and it should just work.

I'm hosting this for free on the Oracle Cloud for personal use. Had to do some server setup to get it to run on the 1 GB AMD servers like using swap memory and removing crashkernel from the boot parameters; I didn't have enough memory out of the box.
